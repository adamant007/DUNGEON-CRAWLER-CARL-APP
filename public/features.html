Crawler Companion TTRPG Features

Crawler Companion is a mobile-first tabletop RPG companion for character creation, live digital character sheets, dice and skill rolls, campaign management, GM workflows, and private rules reference. This page lists the major tools available in the web app in plain language.

Character creation and character sheets

Guided TTRPG Character Creator

Create a character step by step with skills, history, combat choices, and persistent character records.

Live Digital Character Sheet

Use stats, skills, HP, mana, defense, conditions, gear, notes, and play-time controls from one interactive sheet.

Character Save and Load

Keep persistent characters, return to the active character, and switch between saved character records.

Printable Character Sheet

Use a four-page character sheet layout designed for digital play and printing.

Dice, combat, spells, and equipment

Automated Dice and Skill Checks

Roll from the character sheet with character modifiers and skill ranks applied by the app.

HP, Mana, Defense, and Conditions

Track core combat resources and character status while playing at the table.

Attack and Damage Tools

Use attack action cards and keep attack details, damage information, defenses, and combat resources together.

Spells and Action Hotbar

Track spells and keep frequently used attacks, spells, and consumables close to the character sheet.

Gear, Inventory, and Consumables

Manage equipment, inventory quantities, consumables, currency, and character resources.

Crafting and Dimensional Storage

Use built-in character tools for crafting and dimensional storage as part of the same character record.

Campaign and GM tools

RPG Campaign Manager

Create a campaign as GM or join one with an invite code so player characters stay connected to the table.

Guest Character Creation

GMs can create guest characters for players before they have accounts and later hand ownership over with a claim link.

GM Character Viewer and Editor

View and manage campaign-linked character sheets from a campaign-scoped GM workflow.

GM Mob Stat Library

Save, edit, delete, and search private campaign mob stat blocks for quick encounter reference.

Rules and mobile tabletop use

Private RPG Rules Search

Search rules material you provide and keep reference information close to the character and campaign tools.

Phone and Tablet TTRPG Companion

Touch-first controls are designed for phones and tablets so the app remains practical during physical tabletop play.

Roadmap

Maps, deeper combat and initiative workflows, and expanded shared party play are roadmap items. They are intentionally identified as upcoming rather than described as currently available features.
